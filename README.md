# Dukaan Manager Desktop

Windows app for Dukaan Manager (Developer by Noman Powered by alpha blue digital). It is a small desktop window that opens https://shop.alphablue.digital. All shop data stays on the server; this app holds no data and no keys. Internet is required.

Download the latest `Dukaan-Manager-Setup.exe` from the Releases page. Windows may show "Windows protected your PC" because the app is not code-signed: click "More info", then "Run anyway".
